# Planning des salles (SallePlan)
Application React + Vite + Electron. Données stockées localement (localStorage), sauvegarde JSON dans Réglages → Organisation.

## Développement
    npm install
    npm run dev

## Installateur Windows
Pousser sur GitHub : l'action « Build » (onglet Actions) produit l'installateur `.exe` en artefact.
En local sur Windows : `npm install` puis `npm run dist` (dossier `release/`).
